## Executive conclusion

**Decision: INCONCLUSIVE**

The experiment did not satisfy the frozen support criteria for the primary `coupled` mode. The dynamic boundary did self-repair, but the viability horizon showed no measurable boundary dependence at the resolution used, the observability-opacity change was below threshold, and therefore the viability-observability coupling statistic could not be estimated. The history test was saturated at 100% recovery in every mode, so its nominal `Lambda_H = 1.933` is a numerical ratio of near-zero errors and is not interpretable as evidence for history dependence.

This is not a falsification of the broad PH idea. It is a failure of the current toy parameterization to produce a sufficiently informative confirmatory test.

## 1. Tested conjecture

> The viability horizon and the observability horizon are co-generated by the same self-maintained boundary mechanism `B_t`.

Operational quantities:

- `D*`: largest disturbance with estimated recovery probability at least 0.80.
- `Omega`: finite-horizon Bayesian posterior uncertainty, `tr(P_post)/tr(P_prior)`.
- `Gamma_VO`: correlation between `D*` and `Omega` under boundary perturbation.
- `Lambda_H`: shuffled-history prediction error divided by true-history prediction error.
- Boundary repair fraction: fraction of induced boundary error repaired over the audit horizon.

For the `coupled` mode:

- Baseline boundary: `0.599329`
- Boundary repair fraction: `0.991234`
- Viability horizon: `D* = 2.8 -> 2.8`
- Viability drop fraction: `0.000000`

- `Lambda_H`: `1.933068`
- History-test recovery rate: `1.000000`

The main bottleneck is therefore not a weak correlation; the viability proxy itself is flat across all imposed boundary shocks at the selected disturbance-grid resolution.

An additional design issue is visible in `viability_only`: boundary-dependent feedback changes the closed-loop transition matrix used by the observability calculation, so observability can still move indirectly even when the observation matrix itself is held at baseline. This makes the negative control less structurally pure than its name suggests.

## 5. Boundary self-repair

The boundary mechanism behaved as intended under the repair audit. After the imposed shock, it returned toward its target with a repaired fraction of approximately 0.991. This supports only the implementation claim that the toy boundary is self-restoring under its own update rule.

It does not, by itself, support the stronger claim that the same mechanism co-generates viability and observability horizons.

## 6. Why the result is INCONCLUSIVE

Three independent information failures occurred:

1. **No viability dynamic range.** `D*` remained exactly 2.8 throughout the boundary scan. A correlation with a constant variable is undefined.
2. **Observability effect below the frozen threshold.** The coupled-mode opacity change was about 0.0211 versus the required 0.04.
3. **History-test saturation.** All history episodes recovered, making both prediction errors essentially zero. The ratio `Lambda_H` is therefore numerically unstable and should not be treated as evidential.

Because the support criteria fail but the hard-falsification logic is not triggered, the frozen engine returns `INCONCLUSIVE`. The independent audit agrees with that status, while being stricter about the history metric.

## 7. Recommended Phase 1B

A new confirmatory run should not simply retune parameters on these same seeds. Use an independent pilot/calibration split first.

Recommended changes:

- Calibrate the disturbance grid around the empirical recovery transition so `D*` has measurable variance under boundary shocks.
- Choose a history-test disturbance that yields a non-saturated outcome distribution, ideally with recovery probabilities away from 0 and 1.
- Add preregistered estimability gates: minimum variance for `D*`, minimum outcome entropy, and minimum number of successes/failures before computing ratio metrics.
- Redesign negative controls so the `viability_only` manipulation cannot alter the observability state-transition operator used in the opacity metric, and vice versa.
- Run tuning only on pilot seeds, freeze the new configuration and code hash, then execute a fresh confirmatory seed set.

## 8. Scientific scope

This experiment is a toy-system falsification test. It does not establish a biological Personal Horizon, a theory of consciousness, qualia, or first-person ontology. Its value is narrower: it reveals which parts of the operationalization are currently measurable and which are not.

> **The boundary self-repair mechanism works in the toy implementation, but the present design cannot yet test the proposed co-generation of viability and observability horizons with adequate dynamic range.**
