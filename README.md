# PH - Personal Horizon falsification experiments

This repository operationalizes the PH (Personal Horizon) hypothesis as a falsifiable toy dynamical-system program.

## Current experiment

**PH v0.2 / Phase 1 - Toy boundary co-generation falsification**

Primary conjecture:

> The viability horizon and the observability horizon are co-generated by the same self-maintained boundary mechanism.

The experiment tests boundary self-repair, viability sensitivity, finite-horizon observability opacity, viability-observability co-variation, history dependence, and negative controls.

### Current result

**INCONCLUSIVE**.

The boundary repaired strongly, but the viability horizon remained fixed at `D*=2.8` across the boundary-shock scan. The coupled-mode observability-opacity change was below the frozen threshold, so the viability-observability correlation was undefined. The history test was also saturated (`recovery rate = 1.0` in every mode), making its nominal `Lambda_H` ratio non-informative. See `reports/` and `results/phase1/decision.json`.

This result supports neither PH in biology/consciousness nor a general claim that self-maintained boundaries generate first-person experience. It is only an audit of this toy operationalization.

## Reproduce

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python src/ph_v02_full.py
```

The supplied engine writes `ph_v02_results/` by default. The committed `results/phase1/` directory is the frozen result snapshot from the 2026-08-11 execution.
