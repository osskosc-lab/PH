# PH v0.2 - Phase 1 toy falsification protocol

## Conjecture

The viability horizon `H_V` and observability horizon `H_O` are co-generated by the same self-maintained dynamic boundary `B_t`.

Operational proxies in this toy system:

- Viability horizon: critical disturbance `D*` such that recovery probability remains at least `tau = 0.80`.
- Observability horizon: posterior-uncertainty opacity `Omega = tr(P_post) / tr(P_prior)` over a finite observation horizon.
- Co-generation coupling: `Gamma_VO = corr(D*, Omega)` over boundary perturbations.
- History dependence: `Lambda_H = MSE_shuffled / MSE_true` under state-matched history manipulation.
- Self-maintenance: fraction of boundary error repaired after an imposed boundary shock.

## Frozen thresholds in the supplied engine

| Criterion | Threshold |
|---|---:|
| Boundary self-repair | repaired fraction >= 0.80 |
| Viability boundary effect | viability drop >= 0.10 |
| Observability boundary effect | opacity drop >= 0.04 |
| Viability-observability coupling | Gamma_VO >= 0.60 |
| History dependence | Lambda_H >= 1.10 |

Primary mode: `coupled`.

Negative controls:

- `viability_only`
- `observability_only`
- `null`

## Decision rule in the supplied engine

- `SUPPORTED`: all five criteria pass.
- `FALSIFIED`: a hard decoupling or near-null history pattern is detected by the engine's explicit hard-fail logic.
- `INCONCLUSIVE`: mixed/insufficient signals.

## Audit gates applied after execution

The following are treated as interpretation gates, without rewriting the frozen engine decision:

1. A ratio metric is not evidential when the target is saturated/constant. If recovery is 0% or 100% in essentially all history-test episodes, `Lambda_H` is non-informative even if numerically above threshold.
2. `Gamma_VO` is not estimable when `D*` has no variance over the boundary scan.
3. Negative controls must separate the proposed mechanism. A control that changes the state-transition matrix can indirectly change finite-horizon observability and is not a structurally pure observability control.

These gates explain why the Phase 1 result is reported as **INCONCLUSIVE** rather than as support.
