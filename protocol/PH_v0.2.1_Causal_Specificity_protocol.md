# PH v0.2.1 - Causal-Specificity Falsification Experiment

## Scope
This preregistered synthetic experiment validates the **specificity of a PH signature detector**. It does not test whether PH exists in nature.

## Core hypothesis
A selective intervention on one self-maintained boundary mechanism must jointly change viability and observability:

- `do(B) -> Delta H_V`
- `do(B) -> Delta H_O`

Correlation alone is insufficient. The detector must reject split boundaries, common drivers, one-sided couplings, sensor artifacts, and null systems.

## Models
| Mode | Structure | Role |
|---|---|---|
| M0 coupled-PH | B -> V and B -> O | positive control |
| M1 split-boundary | B_V -> V, B_O -> O | independent-boundary adversary |
| M2 common-driver | Z -> V, Z -> O; B non-causal | common-cause adversary |
| M3 viability-only | B -> V | one-sided control |
| M4 observability-only | B -> O | one-sided control |
| M5 sensor-artifact | sensor noise -> observability metrics | artifact control |
| M6 null | no coupling | complete negative control |

For M1, the canonical `do(B)` targets the candidate viability boundary `B_V`; the independent observation boundary `B_O` is not changed.

## Viability horizon
For each seed and intervention, recovery counts are fit by `P_rec(D)=sigmoid(beta0+beta1 D)`. The continuous horizon solves `P_rec(D*)=0.80`. A dynamic-range gate requires an observed region with `0.10 < P_rec < 0.90`.

## Observability
Two endpoints are required: posterior opacity `Omega_H=tr(P_post)/tr(P0)` and Jensen-Shannon distinguishability between observation distributions generated by two protected internal states. With boundary damage (`B` decreases), a PH-like response has `D*` down, `Omega` down, and JS distinguishability up.

## Paired boundary intervention
`delta = {0,.10,.20,.30,.40,.50}` is applied within the same seed. The primary coupling statistic is `Gamma_int = corr(Delta V, Delta Omega)` over non-zero shock-by-seed pairs.

## Sham
A sham intervention introduces a small matched nuisance burden without changing B. The normalized joint boundary effect must be at least 2x the sham effect.

## History
`Lambda_H = E_shuffled/E_true` is evaluated with a paired bootstrap CI. A separate matched-B contrast tests whether history is mediated through the boundary.

## Frozen Gates
- G0 Freeze: source/config/thresholds/seeds hashed.
- G1 Dynamic range: fraction >= 0.90.
- G2 Boundary repair: mean R_B >= 0.80.
- G3 Viability sensitivity: relative D* drop >= 0.10 and bootstrap LCB > 0.
- G4 Observability: opacity effect >= 0.03; JS change reciprocal and LCB > 0.
- G5 Interventional coupling: Gamma_int >= 0.60 and LCB > 0.30.
- G6 Sham specificity: effect ratio >= 2.0.
- G7 History dependence: Lambda_H >= 1.10 and LCB > 1.02.
- G8 Negative-control specificity: M1-M6 must not become complete PH positives.
- G9 Confirmatory holdout: final decision uses independent confirmatory seeds only.
