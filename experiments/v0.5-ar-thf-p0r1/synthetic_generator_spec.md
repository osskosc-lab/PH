# PH v0.5 AR-THF — Frozen Synthetic Generator Specification

Status: P0-r1 specification only. No simulator is authorized yet.

## 1. Numerical integration

All stochastic generators use Euler-Maruyama.

- dt = 0.01 s
- default run length = 30.0 s
- core Brownian diffusion sigma_core = 0.08
- mediator diffusion sigma_med = 0.08
- environment diffusion sigma_env = 0.10
- hidden-memory diffusion sigma_h = 0.05
- common-driver diffusion sigma_c = 0.12
- divergence STOP: ||state||_2 > 1e4
- all finite checks are mandatory

Initial physical core:
(x1,x2,v,o,r)=(0,0,1.40,0,0).
All mediators, environment states, hidden memory and common driver start at 0.
The first 20.0 s are burn-in unless a metric defines a different protocol.

## 2. External input

uS_eff(t) is the deterministic convolution
uS_eff(t)=Integral_0^t 1.5*exp(-1.5*(t-s))*uS(s) ds.

u_eff(t)=0.70*uF(t)+0.30*uS_eff(t).

## 3. Common physical equations

For mediator summaries mB,mV,mO,mI:

dx1=[-0.70*x1+0.55*tanh(x2)+0.20*mB+0.10*uF]dt+0.08dW1

dx2=[-0.65*x2-0.50*tanh(x1)+0.15*mB+0.10*uS_eff]dt+0.08dW2

dv=[aV*v-0.45*v^3+0.20*x1+0.40*mV+0.10*r]dt+0.08dWv

do=[-0.85*o+0.35*x2+0.45*mO]dt+0.08dWo

dr=[-0.60*r+0.30*mB+0.15*v]dt+0.08dWr

A standard mediator z obeys:
dz=[-0.75*z+0.25*x1+0.25*x2+0.20*tanh(v)+0.25*u_eff+q_local]dt+0.08dWz.

Default aV=0.90.

## 4. Environment equations

Default gamma1=0.50, gamma2=0.40.

de1=[-1.00*e1+gamma1*mI]dt+0.10dWe1

de2=[-1.10*e2+gamma2*mI+0.20*e1]dt+0.10dWe2

de3=[-1.00*e3+0.30*e1+0.20*e2]dt+0.10dWe3

de4=[-1.05*e4+0.35*e2]dt+0.10dWe4

de5=[-0.90*e5+0.25*e3+0.20*e4]dt+0.10dWe5

de6=[-0.95*e6+0.30*e4]dt+0.10dWe6

de7=[-0.85*e7+0.25*e5+0.15*e6]dt+0.10dWe7

de8=[-0.80*e8+0.30*e6+0.20*e7]dt+0.10dWe8

## 5. Generator definitions

### G0_shared
One mediator b with standard mediator dynamics.
mV=mO=mI=mB=b.
Physical position of b for local field: r_b=0.00.

### G1_separate
Three standard mediators zV,zO,zI with independent Brownian innovations.
mV=zV, mO=zO, mI=zI, mB=(zV+zO)/2.
Positions: r_zV=-0.25, r_zO=+0.25, r_zI=+0.75.

### G2_common_driver
Hidden c follows dc=-0.25*c dt+0.12dWc.
zV,zO,zI follow standard mediator dynamics with an additional +0.20*c drift term and independent mediator Brownian innovations.
mV=zV, mO=zO, mI=zI, mB=(zV+zO)/2.
Positions identical to G1.

### G3_access_artifact
Dynamics are byte-for-byte G0_shared. The only change is the registered artifact observation operator defined in access_operator_spec.md. No plant coefficient changes are allowed.

### G4_historyless
Dynamics are byte-for-byte G0_shared and use a fresh namespace. This is the H4 Markov/null control.

### G5_history_dependent
Add hidden h:
dh=[-0.40*h+0.60*x1]dt+0.05dWh.
The shared mediator b receives an additional +0.35*h drift term.
mV=mO=mI=mB=b.
The H4 observed-state reset never resets h.

### G6_oracle_clone
Two mediator states zV,zO.
Both receive the same initial value, the same u_eff, the same standard mediator drift, and the same Brownian innovation dWz.
mV=zV, mO=zO, mI=(zV+zO)/2, mB=(zV+zO)/2.
Positions: r_zV=-0.25, r_zO=+0.25.
Under A0, q_local=0 for both, hence zV(t)=zO(t)=b_G0(t) pathwise when paired with G0 common random numbers. This is the analytic A0 equivalence construction.
Under A2, q_local is generated by the model-independent spatial field, so zV and zO can receive different local drive.

### G7_influence_targeted
Dynamics are G0_shared except gamma1=0.90 and gamma2=0.72. No other coefficient changes.

### G8_viability_targeted
Dynamics are G0_shared except aV=0.65. No other coefficient changes.

### G9_observability_targeted
Dynamics are G0_shared. Plant surface transduction etaO=0.35 instead of 1.00 in all observation surfaces. No dynamics coefficient changes.

## 6. Common random numbers

Within any registered paired comparison, non-intervened Brownian substreams are shared.
G0/G6 A0 equivalence uses identical physical-core, environment and mediator innovation substreams.
G1/G2 mediator innovations remain independent by construction.
No analysis may choose a random-stream mapping after seeing outcomes.
